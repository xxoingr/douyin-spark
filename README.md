# douyin-spark

在自己电脑上运行的抖音续火花工具。打开浏览器页面就能管理要续火花的好友、发送的消息和定时时间，支持同时管理多个抖音账号。

> 🚧 **开发中**：网页版已经可以使用（支持多账号，手动点“立即发送”）；每天定时发送、服务器部署还在计划中。

## 计划功能

- **扫码登录**：弹出浏览器窗口扫码，登录状态保存在本地，每次运行后自动续期
- **好友管理**：从抖音拉取会话列表，显示头像、昵称和火花天数，勾选要续火花的好友
- **按 uid 识别好友**：好友改昵称、用 emoji 昵称都不会认错
- **消息模板**：随机抽取消息，支持 `{天数}` 等占位符，可以给某个好友单独设消息
- **多账号**：每个账号有自己的好友勾选和消息模板；点一次发送，所有账号依次执行，同一时间只运行一个浏览器，内存占用不叠加
- **定时发送**：每个账号设置自己的发送时间窗口，在窗口内随机时刻发送
- **今天发没发**：好友列表显示今天有没有给 TA 发过消息（包括在手机上手动发的）
- **运行日志**：每次运行的结果、失败原因和截图都能在页面上查看

## 使用方法

需要 [Node.js](https://nodejs.org/) 24 或更高版本。

```bash
npm install
npx playwright install chromium
npm run build
npm run shortcut
```

之后双击桌面上的 **续火花** 图标即可：服务器在后台启动（不弹窗口），并自动打开 <http://localhost:6688>。关掉网页 10 分钟后服务器自动退出，不用时不占内存。也可以用 `npm start` 手动启动（不会自动退出）。

第一次使用：

1. **账号**页：点“添加账号”，在弹出的浏览器窗口里用手机抖音扫码。要加多个账号就重复这一步，扫码前先在手机抖音里切换到要添加的那个号
2. 右上角选中一个账号，在 **好友** 页点“刷新好友列表”，把要续火花的好友打开开关
3. **消息** 页：给这个账号添加几条消息，发送时会随机挑一条
4. 点右上角 **立即发送（全部账号）**，在“运行记录”页查看每个好友的结果。每点一次，所有勾选的好友都会收到一条（不管今天发没发过）

> 页面只在本机访问（只监听 127.0.0.1），局域网里的其他设备打不开。

## 技术栈

| 部分 | 技术 |
| --- | --- |
| 运行环境 | Node.js 24+ |

| 后端 | Express + SQLite（Node 自带的 `node:sqlite`） |
| 前端 | Vue 3 + Vite + Element Plus |
